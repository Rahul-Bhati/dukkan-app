LLM bill auto-migrator: automatically find classification-shaped LLM calls in a production application (from code and request logs), build an evaluation set from production traffic using the incumbent frontier model's past answers plus limited human labels, and safely migrate those calls to a much cheaper constrained decision model (typed classifier such as a System-One model, or a small/distilled model) with a statistical guarantee that task accuracy does not drop beyond a tolerance, gating the swap in CI.
